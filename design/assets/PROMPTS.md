# Image-generation direction

Tool: built-in `image_gen` (not CLI/API). Each output is a separate complete illustration. The page references are style/composition guidance, not cropped output.

The 24 generation briefs and reference paths in `generation-jobs.json` were prefixed with:

> Generate one high-resolution standalone 3:2 landscape artwork matching the embedded illustration in the reference page. Premium enterprise technology aesthetic, crisp cinematic detail, deep navy #020D18 background, electric blue #0068FF, cyan #00DDF8, selective teal #00E5C3 light. Entire objects inside frame with generous 8% safe margins, outer edges smoothly fade to navy. Reference is style guidance only. No full webpage, no page header/footer/headline, no crop, no watermark.

Four earlier masters use the same visual direction with the preceding project palette: dotted E orbit for About; connected Odoo dashboard; AI chip with four workflow panels; cloud security dashboard with foreground shield. The original full prompts for that first batch were not retained in this file.

The UAE landmark was subsequently corrected with:

> Edit this Dubai skyline illustration: preserve its exact premium cyan blue glass-wireframe style, dark navy background, composition and Burj Khalifa. Remove the Saudi Kingdom Centre tower with a hole at its top on the right side and replace it with Dubai Emirates Towers. The skyline must depict Dubai landmarks only: Burj Khalifa, Burj Al Arab, Emirates Towers. No Riyadh or Saudi landmarks, no text. All buildings fully within frame.
