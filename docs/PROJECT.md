# Project

ETripleSoft is a technology and digital-transformation company serving Egypt, the UAE, and KSA. Its flagship offering is Odoo ERP, supported by AI, web, mobile, cloud and security, and digital-marketing services.

The redesign must communicate a premium enterprise-technology company: confident, technical, and credible. It must not read as a generic digital agency. Odoo should have the strongest homepage hierarchy and a distinct narrative presence.

The intended homepage narrative is:

1. Header
2. Hero
3. Trust
4. Odoo flagship story
5. Services
6. Transformation process
7. Industries
8. Case studies and real work
9. Results
10. Regional presence
11. Testimonials
12. Insights
13. FAQ
14. Final CTA
15. Footer

This order may evolve only through an intentional documented decision, not through incidental template changes. Use verified existing content wherever possible, and preserve editable WordPress content, URLs, SEO, and business functionality throughout the migration.
