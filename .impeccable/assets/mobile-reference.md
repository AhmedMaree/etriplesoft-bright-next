# Mobile page reference assets

All raster files in `public/images/mobile/reference/` are sourced from the user-provided reference directory `assets/images/services/mobile/`.

| Published asset | Source | Use |
| --- | --- | --- |
| `hero.webp` | `hero-image.png` | Mobile app hero artwork |
| `ios.webp`, `android.webp` | `assets.png` | iOS and Android marks |
| `flutter.webp`, `business.webp`, `odoo.webp`, `customer-apps.webp`, `maintenance.webp`, `consultation.webp` | `assets.png` | Service icon crops |
| `user-centric.webp`, `scalable.webp`, `security.webp`, `faster.webp`, `support.webp`, `impact.webp` | `assets.png` | Benefit icon crops |

Each WebP has a neighboring JSON sidecar that records its source and crop purpose.
